# Submission checklist

Verified against official Devpost requirements and announcements on 10 November 2026.

Deadline: **13 November 2026, 01:30 IST** (12 November, 20:00 UTC). Aim for the evening of 12 November.

- [ ] Meaningful PayPal sandbox functionality works with actual credentials.
- [ ] Real AI is integrated and demonstrated; the offline rule baseline is not enough.
- [ ] Public code repository with source, required assets, setup instructions and OSI licence.
- [ ] Working hosted build OR clear complete instructions that judges can run.
- [ ] Necessary test access provided securely; no API keys in public source.
- [ ] Public YouTube demonstration under three minutes showing the real application.
- [ ] Description explains features, PayPal integration, actual AI tools and limitations.
- [ ] All required form fields answered (team/country, new/existing project, tools, experience, eligibility, learning).
- [ ] Optional sponsor tools accurately selected if claiming a sponsor prize.
- [ ] All actual teammates invited and accepted on Devpost.
- [ ] English submission materials or English translations.
- [ ] Rights/licences for third-party code, media and data confirmed.
- [ ] Entry submitted, not merely saved as a draft; submitted status verified.
- [ ] Demo, credentials and credits remain usable until December 21.
- [ ] Freeze submitted repo, README, video and linked materials after deadline until winner announcement, per organizer updates.

Sources: https://paypalaihackathon.devpost.com/ and https://paypalaihackathon.devpost.com/updates and https://paypalaihackathon.devpost.com/rules

Creating this repository does not register or submit the hackathon entry.
